# download-speed-test

Консольный скрипт на Node.js (без внешних зависимостей) для замера скорости скачивания:
делает заданное число последовательных запросов к одному адресу, дожидается полного
ответа на каждый и считает среднее время запроса, объём скачанных данных и скорость.

## Запуск

Нужен Node.js **18 или новее** (используется встроенный `fetch` — ничего устанавливать не надо).

```bash
node speedtest.mjs "https://speed.cloudflare.com/__down?bytes=25000000"
```

Число запросов можно изменить флагом `--requests` (по умолчанию 10):

```bash
node speedtest.mjs "https://speed.cloudflare.com/__down?bytes=25000000" --requests 5
```

В качестве адреса подойдёт любой файл, отдаваемый по HTTP (тяжёлая картинка, архив,
специальный эндпоинт для тестов скорости — как в примере выше: он генерирует 25 МБ данных).

## Единицы измерения

| Величина | Единица | Определение |
|---|---|---|
| Время (запроса и общее) | секунды | — |
| Объём скачанных данных | МиБ | 1 МиБ = 1 048 576 байт (двоичный мегабайт) |
| Скорость скачивания | Мбит/с | 1 Мбит/с = 1 000 000 бит/с (десятичный мегабит, как у провайдеров) |

Скорость считается как весь скачанный объём в битах, делённый на **wall time** —
реальное время от отправки первого запроса до получения последнего ответа.
Запросы идут строго последовательно, поэтому это честная сквозная скорость канала.

## Пример вывода

```
Адрес: https://speed.cloudflare.com/__down?bytes=10000000
Запросов: 3, последовательно

#1: 1.24 с, 9.54 МиБ
#2: 1.20 с, 9.54 МиБ
#3: 0.71 с, 9.54 МиБ

— Итог —
Среднее время запроса: 1.05 с
Скачано: 28.61 МиБ
Общее время: 3.16 с
Скорость: 75.96 Мбит/с
```

## Замечания по реализации

- Тело ответа дожидается полностью через `response.arrayBuffer()` — `fetch` в Node.js
  считывает ответ целиком, а не только заголовки.
- Статус отличного от 2xx ответа считается ошибкой: скрипт печатает код и завершается
  с ненулевым exit-кодом (удобно для автоматизации).
- `performance.now()` используется вместо `Date.now()` — монотонные часы не прыгают
  от перевода системных часов.
